# 8. Conclusion

NormCode Canvas demonstrates that "observe and control" is achievable for AI
agent workflows — not as a post-hoc instrumentation layer, but as a structural
property of the language itself. The two scenarios shown here — a full lifecycle
run of the PPT Agent and a debug-and-fork session on the Code Assistant — are
not cherry-picked demonstrations. They represent the daily workflow the system
is built for: plan it, review it in plain English before it runs, watch it
execute step by step, fix the one step that's wrong, fork if you need to
compare. The plan file is yours when you're done — a portable text document
that belongs to no platform.

The Canvas App (v1.1.3), the NormCode language, compiler, and orchestrator are
available now. The live PPT Agent demo is at [URL]. The formal language
specification is in [CITE: arXiv:2512.10563].
