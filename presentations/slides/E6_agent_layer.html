E6 Agentic Design
Four Agents. Independent Contexts. Shared Across Plans.
user_agent
Abilities
Human-in-the-loop — read input, send responses, await approval
Conversation — reason over history, resolve ambiguity
Intent resolution — classify operator messages
Appears in
uav_user_assistant.ncds uav_analysis_criteria.ncds
Isolated from: drone telemetry, flight commands, sensor readings, image data
drone_agent
Abilities
Drone interface — send flight commands, receive telemetry
Sensor interface — trigger scans, collect sensor data
Camera interface — trigger capture, receive raw images
Appears in
uav_navigation.ncds uav_error_check.ncds
Isolated from: operator conversation, session history, intent, mission-level state
analysis_agent
Abilities
Image analysis — inspect images for defects, anomalies, patterns
Criteria reasoning — apply and adapt analysis criteria
File I/O — read captured images, write structured findings
Appears in
uav_error_check.ncds uav_analysis_criteria.ncds
Isolated from: flight commands, operator conversation, telemetry, how images were captured
planning_agent
Abilities
Mission reasoning — triage requests, assess mission components
Code execution — rule-based route planning, waypoint filtering
File I/O — read mission plans, write structured reports
Appears in
uav_mission.ncds uav_navigation.ncds uav_error_check.ncds
Isolated from: operator conversation history, drone hardware, raw sensor data
