1
Agentic Design Configure the abilities
The ability pool — code execution, human-in-the-loop, file I/O, sensors. Workers draw from it; nothing outside is reachable.
Defined once per workflow run. A navigation mission and an error-check mission can expose different ability sets.
2
Workflow Design Define the works
Each step in the .ncds declares its deliverable, its task, and its scoped inputs. Syntactic nodes run without LLM. Semantic nodes assign a worker.
The boundary between fixed and adaptive is authored into the contract — not discovered at runtime.
3
Continual Engagement Enable bounded improvisation
ReAct loop: worker iterates within a step's scope. Distribute Tool: worker delegates to a sub-worker with a subset of its inputs.
Adaptation happens — but it is bounded by the declared scope. The contract is not rewritten at runtime.
Mature Automation
Syntactic nodes carry our existing rule logic
Deterministic, zero LLM latency, fully auditable
Route planning, waypoint loops, anomaly rules — unchanged
Self-Improvisation
Semantic nodes assign workers with configured abilities
ReAct loop and Distribute Tool enable in-scope adaptation
Novel cases, ambiguous input, intelligent judgment — bounded
