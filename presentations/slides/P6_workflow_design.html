The two node types

Syntactic Node
Deterministic, rule-based execution — no LLM involved
Zero latency, zero cost, fully auditable
This is where our existing automation lives — route planning, waypoint loops, sensor collection, anomaly rules
Behavior is constrained by the rule set — identical to today
Semantic Node
A worker is assigned — one agent or a group
Worker receives only the inputs declared in the step's scope
Worker applies configured abilities to produce the declared deliverable
Adapts, reasons, handles novel cases — but cannot exceed its scope
The boundary between fixed and adaptive is explicit in the contract — declared at authoring time, not discovered at runtime.
