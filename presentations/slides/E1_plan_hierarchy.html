What each plan is

Each plan is a scope-isolated contract
No plan reaches outside its declared inputs. The Distribute arrows are the only connections — and each one passes only what the receiving plan declares it needs.

Agent legend

user_agent Operator-facing interaction only
drone_agent UAV hardware and sensors only
analysis_agent Image and data analysis only
planning_agent Mission structure and reporting
Agents are shared across plans — but each invocation is a fresh, scoped call. Sharing capability does not mean sharing context.
