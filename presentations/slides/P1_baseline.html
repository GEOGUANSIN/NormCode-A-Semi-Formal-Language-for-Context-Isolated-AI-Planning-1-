P1 The Problem
Our Rule-Based Automation Works. But It Has a Ceiling.

Rule-based automation stack

Mission Input deterministic
↓
Route Planning Algorithm deterministic
↓
Waypoint Execution Loop deterministic
↓
Sensor Data Collection deterministic
↓
Anomaly Detection Rules deterministic
↓
Report Generation deterministic
What this does well
  • Repeatable — same input produces the same output, every time
  • Auditable — every decision is traceable to a rule
  • Fast — no LLM latency on deterministic steps
  • Bounded — behavior is constrained by the rule set
What it cannot do
  • Handle terrain or obstacle types outside the rule set
  • Adapt when the mission brief is ambiguous or novel
  • Learn from past missions to improve future ones
  • Reason about tradeoffs between competing objectives
  • Scale to new mission types without re-engineering rules
Rule-based automation is our foundation. It is not going away. The question is what we build on top of it.
